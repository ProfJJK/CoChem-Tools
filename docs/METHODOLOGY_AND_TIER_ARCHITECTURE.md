# Comprehensive Computational Materials and Methods

This document provides the complete **Materials and Methods** text, script-by-script architecture, mathematical equations, convergence thresholds, and BibTeX citation keys for every computational methodology and workflow step executed in the **$\mathrm{HCOOH\cdots H_2S}$ (`hcooh-hsh`, Project SR3)** and **$\mathrm{HCOOH\cdots N_2O}$ (`hcooh-nno`, Project SR4)** campaigns.

## 1. Overview of the Multi-Tier Computational Funnel & Hardware Queue Architecture

All quantum-chemical, classical/machine-learning force-field (ML/FF), topological, and rotational-spectroscopic calculations were orchestrated through a deterministic, checksum-verified multi-tier computational pipeline:

$$\text{Tier 1: Global Exploration (\texttt{GOAT/GFN2-xTB} + 1200-Start Batched GPU \texttt{MACE-OFF24(M)})} \;\longrightarrow\; \text{Tier 2A (GPU-First Basin Filter): \texttt{GPU4PySCF} }\omega\text{B97X-V/def2-TZVPP (\& }\omega\text{B97M-V/def2-TZVPPD) Opt + Analytic Hessian}$$
$$\longrightarrow\; \text{Tier 2B (Concurrent CPU Validation): \texttt{r2SCAN-3c} TightOpt + Freq \& 6-Model ML/FF Benchmark} \;\longrightarrow\; \text{Tier 3: \texttt{revDSD-PBEP86-D4/jun-cc-pV(T+d)Z} + \texttt{GPU4PySCF} }\omega\text{B97X-V/def2-TZVPP \texttt{VPT2}} \;\longrightarrow\; \text{Tier 4: \texttt{DLPNO-CCSD(T1)/CBS} + \texttt{DLPNO-SE} + \texttt{LED} + \texttt{QTAIM/IGMH}}$$

### Script & Queue Orchestration (`_publication/queue/campaign_queue.py`)
* **Single-Instance ORCA Hardware Serialization**: All CPU-bound ORCA 6.1.1 [@Neese2020; @Neese2022] jobs are dispatched sequentially from priority-ordered JSON specifications (`_publication/queue/jobs/*.json`) by the workstation queue daemon (`_publication/queue/campaign_queue.py`) under a system-wide lock (`%TEMP%\orca_one_job_at_a_time.lock`). Each production job runs on $8$ MPI ranks (`%pal nprocs 8 end`, `%maxcore 3000`) pinned to physical performance cores while respecting process-creation rate guards (`guard_state.json`) and per-job wall/stall watchdogs.
* **Independent GPU Execution Channel**: All GPU-accelerated machine-learning force-field (`PyTorch` / `ASE` [@Larsen2017]) and density-functional (`GPU4PySCF 1.9.0` [@Sun2018; @Sun2020; @Wu2024; @Li2024]) calculations execute on the workstation's **NVIDIA GeForce RTX 3090 GPU (24 GB GDDR6X VRAM, CUDA 12)** without contending for the CPU ORCA lock.
* **Schema & Determinism Validation (`_publication/style/pubstyle.py`)**: Every intermediate CSV, Excel workbook (`.xlsx`), LaTeX table (`.tex`), Word table (`.docx`), figure (`.pdf`/`.png`), and compiled manuscript is validated against strict column/unit schemas (`pubstyle.check_results(..., strict=True)`) and deterministic ZIP/XML archive normalization (`build_energy_tables.py`, `build_tables.py`).

## 2. Step-by-Step Materials and Methods by Methodology

### 2.1. Global Conformational Exploration (`ORCA GOAT` & `MACE-OFF24(M)` GPU Basin Hopping)

1. **Semiempirical Tight-Binding Global Search (`ORCA GOAT / GFN2-xTB`)**:
   - *Methodology*: The six-dimensional intermolecular configuration space of each binary complex was explored using the Global Optimizer Algorithm (`GOAT`) [@deSouza2025] implemented in ORCA 6.1.1 [@Neese2020; @Neese2022] paired with the self-consistent multipole tight-binding Hamiltonian `GFN2-xTB` [@Bannwarth2019] (`! GFN2-xTB GOAT`). Separate searches were seeded from *trans*-$\mathrm{HCOOH}$ (the gas-phase monomer global minimum) and *cis*-$\mathrm{HCOOH}$ ($+3.90\text{ kcal mol}^{-1}$ experimentally [@Winnewisser2002]), yielding 14 candidate structures for $\mathrm{HCOOH\cdots H_2S}$ (`isomer-00`..`13`) and 21 candidate structures for $\mathrm{HCOOH\cdots N_2O}$ (`isomer-00`..`20`).
   - *Transition-State Exploration (`GOAT-TS`)*: Candidate interconversion saddle points (`transition_states.xyz`) were generated via `GOAT` transition-state searches for subsequent analytical-Hessian verification.

2. **7-Phase Batched In-Process Equivariant MLFF Isomer Search & Hierarchical Deduplication (`MACE-OFF24(M)`)**:
   - *Scripts*: `hcooh-hsh/maceoff24m_search_600/mace_off24m_isomer_search.py` and `hcooh-nno/maceoff24m_search_600/mace_off24m_isomer_search.py` (with comparison figure script `hcooh-hsh/method_comparison/plot_isomer_search_comparison.py`).
   - *Methodology*: Coupling ORCA `GOAT` to external ML potentials via ORCA's `ExtOpt` interface incurred $\sim 3.5\text{ s}$ per gradient call due to subprocess spawning overhead ($\sim 97\text{ h}$ projected runtime). We engineered an in-process, GPU-vectorized 7-phase conformational search and deduplication engine using **`MACE-OFF24(M)`** (`MACE-OFF-24M`) [@Kovacs2025; @Batatia2022] on the RTX 3090 GPU:
     1. **Phase 1 (Monomer Reference Relaxation)**: Isolated *trans*-$\mathrm{HCOOH}$, *cis*-$\mathrm{HCOOH}$, $\mathrm{H_2S}$, and $\mathrm{N_2O}$ were relaxed in `float64` via `BFGS` ($f_{\max} \le 2.0 \times 10^{-4}\text{ eV \AA}^{-1}$).
     2. **Phase 2 (Stratified 5-DOF $\mathrm{SO}(3)\times S^2$ Shell + Sobol Seeding)**: Using deterministic `PCG64` seeding (`SEED = 20260411`), $1200$ random dimer placements ($600$ *trans* + $600$ *cis*) plus literature/GFN2 seeds ($1204$ total starts in $\mathrm{HCOOH\cdots H_2S}$; $1209$ in $\mathrm{HCOOH\cdots N_2O}$) were generated on $R_{\mathrm{COM}} \sim \mathcal{U}(3.0\text{ \AA}, 4.8\text{ \AA})$ with Haar-uniform $\mathrm{SO}(3)$ partner orientations, rejecting clashes with $d_{ij} < 1.75\text{ \AA}$.
     3. **Phase 3 (Vectorized `float32` Batched `FIRE` Coarse Relaxation)**: A custom `BatchedMace` graph wrapper packs $B = 256$ dimer graphs ($2048$ atoms) into a single block-diagonal GPU forward/backward pass and relaxes all $B$ systems simultaneously using vectorized `FIRE` (`batched_fire`) [@Bitzek2006] ($450$ steps, $f_{\max} \le 5.0 \times 10^{-3}\text{ eV \AA}^{-1}$, max step $0.15\text{ \AA}$, COM tether $k = 0.50\text{ eV \AA}^{-2}$ for $R_{\mathrm{COM}} > 5.8\text{ \AA}$). Phase 3 converged $1192/1204$ ($99.0\%$) starts in $11.42\text{ min}$ ($1.76\text{ starts s}^{-1}$) for $\mathrm{HCOOH\cdots H_2S}$ (discovering $9/9 = 100\%$ of final families by Batch 3 at $t = 8.32\text{ min}$) and $1120/1209$ ($92.6\%$) starts in $14.82\text{ min}$ ($1.36\text{ starts s}^{-1}$) for $\mathrm{HCOOH\cdots N_2O}$ (discovering all $28$ families by Batch 4 at $t = 14.22\text{ min}$).
     4. **Phase 4 (Coarse Deduplication & `float64` `BFGS` Tight Refinement)**: Coarse endpoints were pre-clustered by sorted interatomic distance-matrix fingerprints ($\max|\Delta D_{ij}| < 0.12\text{ \AA}$, $\Delta E < 0.08\text{ kcal mol}^{-1}$) and symmetry-aware Kabsch $\mathrm{RMSD} < 0.12\text{ \AA}$ into $365$ ($\mathrm{H_2S}$) and $440$ ($\mathrm{N_2O}$) coarse basins, each tightly refined in `float64` `BFGS` ($f_{\max} \le 3.0 \times 10^{-4}\text{ eV \AA}^{-1}$, $600$ steps; $19.25\text{ min}$ in $\mathrm{H_2S}$, $36.08\text{ min}$ in $\mathrm{N_2O}$), discarding unbound structures ($R_{\mathrm{COM}} > 6.0\text{ \AA}$, $d_{\mathrm{inter},\min} > 4.2\text{ \AA}$, or $\Delta E_{\mathrm{bind}} > -0.20\text{ kcal mol}^{-1}$).
     5. **Phase 5 (Hierarchical Geometry-First Symmetry & Enantiomeric Deduplication)**: Stage A merges fine duplicates if $|\Delta E_i - \Delta E_j| \le 0.05\text{ kcal mol}^{-1}$ and $|\Delta B_\alpha|/B_\alpha \le 1.5\%$ ($\le 15\text{ MHz}$) with $\mathrm{RMSD}_{\mathrm{sym}} \le 0.18\text{ \AA}$, or pure permutation- and reflection-invariant Kabsch $\mathrm{RMSD}_{\mathrm{sym}} \le 0.12\text{ \AA}$ [@Kabsch1976]. Stage B (Phase 6b) applies single-linkage clustering ($\mathrm{RMSD}_{\mathrm{sym}} \le 0.30\text{ \AA}$ and $|\Delta E_i - \Delta E_j| \le 0.30\text{ kcal mol}^{-1}$) to merge flat torsional sub-minima into canonical conformational families ($13$ raw minima $\to 12$ geometry-unique $\to \mathbf{9\text{ families}}$ in $\mathrm{H_2S}$; $38$ raw minima $\to \mathbf{28\text{ families}}$, $26$ bound dimers in $\mathrm{N_2O}$).
     6. **Phase 6 (Analytic MACE Hessian Verification & Saddle Mode-Following)**: Central finite-difference `float64` MACE Hessians ($\delta = 0.002\text{ \AA}$) were Eckart-projected; any saddle point ($\tilde{\nu}_1 < -5.0\text{ cm}^{-1}$) was automatically displaced ($\pm 0.15\text{ \AA}\cdot\mathbf{q}_1/\|\mathbf{q}_1\|$) and re-optimized with `float64` `BFGS` until $N_{\mathrm{imag}} = 0$ ($0.93\text{ min}$ in $\mathrm{H_2S}$, $1.40\text{ min}$ in $\mathrm{N_2O}$). Total wall time was **$31.6\text{ min}$** in $\mathrm{HCOOH\cdots H_2S}$ ($9.2\times$ faster than `GFN2-xTB GOAT` at $291.3\text{ min}$, recovering $8/8 = 100\%$ of verified DFT minima vs. $7/8$ for `GOAT`) and **$52.3\text{ min}$** in $\mathrm{HCOOH\cdots N_2O}$ ($9.4\times$ faster than `GFN2-xTB GOAT` at $489.3\text{ min}$, recovering $18$ vs. $11$ verified DFT minima and resolving the `GFN2-xTB` global-minimum inversion).

### 2.2. Ensemble Deduplication, Symmetry/Enantiomer Filtering & Literature Mapping (`build_working_sets.py`)

* *Scripts*: `_publication/style/build_working_sets.py`, `hcooh-nno/results/CH2O2-N2O/literature_match/`.
* *Deduplication Criteria*: Candidate structures within $12.0\text{ kcal mol}^{-1}$ of the global minimum were grouped by:
  1. Relative electronic energy $|\Delta E_i - \Delta E_j| \le 0.05\text{ kcal mol}^{-1}$,
  2. Principal rotational constants $|A_i - A_j|, |B_i - B_j|, |C_i - C_j| \le 15.0\text{ MHz}$ and planar moments $P_{cc} = \frac{1}{2}(I_a + I_b - I_c)$,
  3. Optimal Kabsch root-mean-square coordinate deviation [@Kabsch1976] $\mathrm{RMSD} \le 0.15\text{ \AA}$, explicitly optimizing over both proper rotations ($\det\mathbf{U} = +1$) and improper reflections ($\det\mathbf{U} = -1$, accounting for mirror-image enantiomers across the $\mathrm{HCOOH}$ plane) as well as permutations of chemically identical nuclei (the two $\mathrm{H_2S}$ protons).
* *Working-Set Condensation*:
  - In **$\mathrm{HCOOH\cdots H_2S}$**, four enantiomeric/near-degenerate groups merged (`02/03/04 -> isomer-02`, `06/07 -> isomer-06`, `08/09 -> isomer-08`, `10/11/12 -> isomer-10`), condensing 14 candidates into **8 unique working-set conformers** (`isomer-00, 01, 02, 05, 06, 08, 10, 13`).
  - In **$\mathrm{HCOOH\cdots N_2O}$**, removing one unconverged duplicate (`isomer-20`) and merging three *cis* clusters (`10/11 -> isomer-10`, `14/15/17 -> isomer-15`, `18/19 -> isomer-18`) condensed 21 candidates into **16 unique working-set conformers** (`isomer-00..10, 12, 13, 15, 16, 18`), which were mapped 1-to-1 onto all 17 published `MP2/6-311++G(2d,2p)` and `CCSD(T)-F12a/VDZ-F12` [@Adler2007] structures (`1t–8t`, `1c–9c`) of Duarte, Rekola, and Khriachtchev [@Duarte2017].

### 2.3. Six-Model Popular Classical & Machine-Learning Force-Field Benchmark (`_tools/run_mlff_benchmark.py`)

* *Scripts*: `_tools/run_mlff_benchmark.py`, `hcooh-hsh/method_comparison/build_method_comparison.py`, `publication/tables/build_tables.py`, `publication/energetics/tables/build_energy_tables.py`.
* *Benchmark Scope*: All **4 isolated monomers** (`trans-HCOOH`, `cis-HCOOH`, `H2S`, `N2O`), all **8 $\mathrm{HCOOH\cdots H_2S}$ working-set dimers**, and all **16 $\mathrm{HCOOH\cdots N_2O}$ working-set dimers** were fully optimized (`L-BFGS`, $f_{\max} \le 5.0 \times 10^{-4}\text{ eV \AA}^{-1}$, max 600 steps) and subjected to harmonic frequency, zero-point vibrational energy ($\mathrm{ZPE} = \frac{1}{2}\sum_k h c \tilde{\nu}_k$), and complexation vibrational shift ($\Delta\tilde{\nu}_k = \tilde{\nu}_k^{\mathrm{dimer}} - \tilde{\nu}_k^{\mathrm{monomer}}$) analyses using the **six most widely used force fields and machine-learning interatomic potentials (MLIPs) in the chemical literature**:
  1. **`MMFF94s`** [@Halgren1996; @Halgren1999]: The static variant of Halgren's Merck Molecular Force Field implemented in `RDKit` (`2024.03`) [@Landrum2024]. Bond orders and aromaticity/conjugation perception were assigned from connectivity, and `AllChem.MMFFGetMoleculeForceField` was initialized with `mmffVariant="MMFF94s"` and **`ignoreInterfragInteractions=False`** so that buffered-14-7 van der Waals and partial-charge electrostatic terms were evaluated across disconnected monomer fragments.
  2. **`GFN-FF`** [@Spicher2020]: Spicher and Grimme's topology-automated generic polarizable force field incorporating electronegativity-equilibration (`EEQ`) atomic charges, bond-order-dependent force constants, and `D4` London dispersion [@Caldeweyher2019], executed via `xtb 6.7.1` (`--gfnff --opt vtight --hess`).
  3. **`ANI-2x`** [@Devereux2020; @Smith2017]: The 8-model ensemble of Behler–Parrinello high-dimensional neural network potentials [@Behler2007] parameterized for $\mathrm{H, C, N, O, F, Cl, S}$ on $\sim 8.9 \times 10^6$ $\omega\text{B97X/6-31G(d)}$ molecular conformations, evaluated in double precision on the RTX 3090 GPU via `TorchANI 2.2.4` [@Gao2020].
  4. **`AIMNet2`** [@Anstine2025]: The 4-model ensemble `aimnet2_wb97m_d3_0` (`aimnet 0.2.1`) combining short-range message-passing neural network interactions with neural spin/charge equilibration (`NSE`) long-range Coulomb electrostatics and `D3(BJ)` dispersion [@Grimme2010; @Grimme2011], trained against $\omega\text{B97M-D3/def2-TZVPP}$ reference data across 14 chemical elements.
  5. **`MACE-OFF-23L`** (`MACE-OFF23(L)`) [@Kovacs2025; @Batatia2022]: The large higher-body-order ($\nu=3$ correlation order, $L_{\max}=2$ equivariant tensor channels, $5.0\text{ \AA}$ layer cutoff) message-passing force field trained on the SPICE-1 dataset [@Eastman2023] at the $\omega\text{B97M-D3(BJ)/def2-TZVPPD}$ level.
  6. **`MACE-OFF-24M`** (`MACE-OFF24(M)`) [@Kovacs2025; @Batatia2022]: The medium equivariant message-passing force field featuring an extended $6.0\text{ \AA}$ per-layer receptive field trained on the expanded SPICE-2 dataset [@Eastman2023] at the $\omega\text{B97M-D3(BJ)/def2-TZVPPD}$ level.
* *Finite-Difference Harmonic Hessian & Eckart Projection*: For each converged stationary point ($N$ atoms), the $3N \times 3N$ Cartesian force-constant matrix was constructed by central finite differences of analytical atomic forces ($\delta = \pm 0.005\text{ \AA}$, $6N$ force evaluations per molecule):
  $$H_{3i+\alpha,\,3j+\beta} = -\frac{F_{i\alpha}(\mathbf{R} + \delta\mathbf{e}_{j\beta}) - F_{i\alpha}(\mathbf{R} - \delta\mathbf{e}_{j\beta})}{2\delta}, \quad \tilde{H}_{ab} = \frac{H_{ab} + H_{ba}}{2\sqrt{m_a m_b}}$$
  Three center-of-mass translations and three rigid-body Eckart rotations ($I_{\alpha\beta}$ eigenvectors) were projected out via QR-orthonormalized projector $\mathbf{P} = \mathbf{I} - \mathbf{D}\mathbf{D}^\top$, and the remaining $3N-6$ eigenvalues ($3N-5$ for linear $\mathrm{N_2O}$) were converted to harmonic wavenumbers $\tilde{\nu}_k$. Intramolecular fundamental shifts ($\Delta\nu_{\mathrm{OH}}, \Delta\nu_{\mathrm{C=O}}, \Delta\nu_{\mathrm{CH}}, \Delta\tau_{\mathrm{COH}}$, plus $\Delta\nu_{\mathrm{SH}}, \Delta\delta_{\mathrm{HSH}}$ or $\Delta\nu_{\mathrm{NN}}, \Delta\nu_{\mathrm{NO}}$) were assigned by maximum mode-localization overlap on the monomer sub-blocks.

### 2.4. Tier-2 Dual GPU/CPU Basin Filter: GPU-First `GPU4PySCF` $\omega\text{B97X-V/def2-TZVPP}$ Followed by Concurrent CPU `r2SCAN-3c` Validation

* *Scripts*: `_tools/gpu4pyscf_wb97xv.py`, `_tools/run_wb97xv_audit_and_preopt.py`, `hcooh-hsh/maceoff24m_search_600/run_r2scan3c_queue.ps1`, `_publication/queue/jobs/004_nno_mace_r2scan_*.json`.
* *Tier 2A (GPU-First Basin Filter & Saddle Audit, `GPU4PySCF` $\omega\text{B97X-V/def2-TZVPP}$)*:
  - Because **`GPU4PySCF 1.9.0`** [@Sun2018; @Sun2020; @Wu2024; @Li2024] executes a complete range-separated hybrid **`wB97X-V/def2-TZVPP`** ($\omega\text{B97X-V/def2-TZVPP}$) [@Mardirossian2014; @Vydrov2010; @Weigend2005; @Weigend2006] optimization and analytical CPKS + analytical `VV10` Hessian on the RTX 3090 GPU in $91.1\text{ s}$ per structure ($55.2\text{ s}$ for a single SCF + analytic Hessian, or $65.9\text{ s}$ with meta-GGA **`wB97M-V/def2-TZVPP`** [@Mardirossian2016] and $82.2\text{ s}$ with diffuse-augmented **`wB97M-V/def2-TZVPPD`** [@Rappoport2010]; **$25.92\times$ faster** than 8-core CPU ORCA at $2362.0\text{ s}$), the Tier-2 Basin Filter runs GPU DFT first.
  - All `MACE-OFF24(M)` and `GOAT` survivors are optimized in delocalized internal coordinates (`coordsys="dlc"`) via **`geomeTRIC 1.1.1`** [@Wang2016] (`conv_tol = 1e-10` $\mathrm{E_h}$, $(99, 590)$ KS grid, $(50, 194)$ `VV10` grid) and verified by analytical GPU Hessians (`auxbasis_response = 1`). Planar $C_s$ saddle points (`hcooh-hsh isomer-06`, `hcooh-nno isomer-03, 10, 13`) are automatically displaced along their normalized lowest imaginary eigenvector ($\Delta\mathbf{x} = 0.25\,\mathbf{q}_1 / \|\mathbf{q}_1\|_\infty$) and re-optimized to true $C_1$ minima ($n_{\mathrm{imag}} = 0$ across all $30/30$ structures, `wb97xv_gpu_revdsd_preopt.csv`). Transition-state candidates are simultaneously audited (`wb97xv_gpu_saddle_audit.csv`).
* *Tier 2B (Concurrent CPU `r2SCAN-3c` Cross-Validation)*:
  - Feeding the GPU-converged $\omega\text{B97X-V/def2-TZVPP}$ geometries into CPU **`r2SCAN-3c`** [@Grimme2021; @Furness2020; @Caldeweyher2019; @Kruse2012] (`! r2SCAN-3c TightOpt Freq DefGrid3`) and Tier-3 `revDSD-PBEP86-D4` (`S1`) cuts CPU optimization steps by $>4\times$ (completing `revDSD S1` in $135\text{ s}$ per isomer, a **$14.6\times$ end-to-end speedup**) while saturating GPU and CPU channels concurrently.

### 2.5. Literature Justification & Benchmark of `GPU4PySCF` $\omega\text{B97X-V/def2-TZVPP}$ (and $\omega\text{B97M-V/def2-TZVPPD}$) for `VPT2` Force Fields of van der Waals Complexes

* *Scripts*: `hcooh-hsh/ftmw_stage2/gpu4pyscf_wb97xv_vpt2.py` and `hcooh-nno/ftmw_stage2/gpu4pyscf_wb97xv_vpt2.py`.
* *Literature & Physical Superiority over `B3LYP-D4/jun-cc-pV(T+d)Z`*:
  1. **Benchmark Accuracy on Noncovalent Dimers (`MGCDB84` & `GMTKN55`)**: Across Head-Gordon's 4986-data-point `MGCDB84` database [@Mardirossian2014; @Mardirossian2016; @Mardirossian2017] and Goerigk and Grimme's `GMTKN55` benchmark [@Goerigk2017; @Najibi2018], $\omega\text{B97M-V}$ and $\omega\text{B97X-V}$ rank `#1` and `#2` among all hybrid density functionals for noncovalent interactions ($\mathrm{WTMAD\text{-}2} = 1.56$ and $1.98\text{ kcal mol}^{-1}$ vs. $3.92\text{ kcal mol}^{-1}$ for `B3LYP-D4`; `S66` $\mathrm{RMSE} = 0.15$ and $0.18\text{ kcal mol}^{-1}$ vs. $0.31\text{ kcal mol}^{-1}$ for `B3LYP-D4`).
  2. **Elimination of Lone-Pair Self-Interaction / Delocalization Error**: `B3LYP` uses $20\%$ global exchange, over-delocalizing sulfur $3p^2$, oxygen $2p^2$, and $\mathrm{N_2O}$ $\pi$ lone pairs. Both $\omega\text{B97X-V}$ ($16.7\%$ short-range, $100\%$ long-range exact exchange, $\omega = 0.30\text{ a}_0^{-1}$) [@Mardirossian2014] and $\omega\text{B97M-V}$ ($15\%$ short-range, $100\%$ long-range exact exchange) [@Mardirossian2016] restore exact $-1/r$ asymptotic exchange, reproducing `revDSD-PBEP86-D4` rotational constants within $+0.036\%$ ($\Delta B_e = +0.79\text{ MHz}$ on $\mathrm{HCOOH\cdots H_2S}$ `isomer-00`).
  3. **Self-Consistent `VV10` Nonlocal Dispersion vs. Classical Pairwise `D4`**: Unlike the classical atomic pairwise `D4` potential in `B3LYP-D4`, the `VV10` nonlocal correlation kernel [@Vydrov2010] depends explicitly on the electron density $\rho(\mathbf{r})$ and gradient $|\nabla\rho(\mathbf{r})|$ at every normal-mode displacement $\pm\delta q_r$, capturing charge-transfer-coupled dispersion anharmonicity in cubic ($\Phi_{rrs}$) and quartic ($\Phi_{rrss}$) force constants [@Brauer2016].
  4. **Analytical GPU Hessians & Noise-Free Cyvin–Watson Quartic Centrifugal Distortion**: `GPU4PySCF 1.9.0` computes analytical RKS + `VV10` Hessians (`auxbasis_response = 1`) on the RTX 3090 GPU in $55.2\text{ s}$ (`wB97X-V/def2-TZVPP`), $65.9\text{ s}$ (`wB97M-V/def2-TZVPP`), $66.9\text{ s}$ (`wB97X-V/def2-TZVPPD`), $82.2\text{ s}$ (`wB97M-V/def2-TZVPPD`), and $211.9\text{ s}$ (`wB97M-V/def2-QZVPPD`) [@Weigend2005; @Rappoport2010], providing exact Cyvin–Watson quartic centrifugal distortion tensors $\tau_{\alpha\beta\gamma\delta}$ [@Cyvin1968; @Watson1977] free of finite-difference noise.

### 2.6. Double-Hybrid DFT Equilibrium Structures, Quadrupole Tensors & `GPU4PySCF` $\omega\text{B97X-V/def2-TZVPP}$ `VPT2` (`hcooh-hsh-mw-predict.py` & `gpu4pyscf_wb97xv_vpt2.py`, Stages `S1`–`S4`)

* *Scripts*: `hcooh-hsh/HCOOH-H2S_mw_predictions/hcooh-hsh-mw-predict.py` and `ftmw_stage2/gpu4pyscf_wb97xv_vpt2.py`.
* *Stage `S1` (`revDSD-PBEP86-D4/jun-cc-pV(T+d)Z` & Composite `DLPNO-SE` Equilibrium Geometry)*:
  - Starting from the GPU-preoptimized $\omega\text{B97X-V/def2-TZVPP}$ geometries, unconstrained equilibrium optimizations were carried out in ORCA 6.1.1 [@Neese2022] using **`revDSD-PBEP86-D4/jun-cc-pV(T+d)Z`** [@Santra2019; @Caldeweyher2019; @Papajak2011; @Dunning1989; @Kendall1992; @Dunning2001] following Barone and Puzzarini [@Barone2020; @Puzzarini2021; @Melli2024] (`! revDSD-PBEP86-D4 jun-cc-pV(T+d)Z VeryTightOpt TightSCF DefGrid3 NoFrozenCore RIJCOSX def2/J aug-cc-pVTZ/C` [@Neese2009; @Weigend2006; @Hattig2005]), paired with composite `DLPNO-CCSD(T)/def2-TZVPPD` semi-experimental equilibrium refinement ($R_e^{\mathrm{SE}}$).
* *Stage `S2a` (Relaxed MP2 Principal-Axis Dipoles & Electric Field Gradient Tensors)*:
  - Single-point relaxed MP2 density evaluations (`%mp2 Density Relaxed end`, `%elprop Dipole true Quadrupole true EFG true end`) yielded $|\mu_a|, |\mu_b|, |\mu_c|$ and nuclear quadrupole coupling constants $\chi_{\alpha\beta}(k) = (e Q_k / h) V_{\alpha\beta}^{\mathrm{PAS}}(k)$ using $Q(^{33}\mathrm{S}) = -67.8\text{ mb}$ ($I = 3/2$) and $Q(^{14}\mathrm{N}) = +20.44\text{ mb}$ ($I = 1$) [@Pyykko2018].
* *Stage `S2b` (`revDSD` Harmonic ZPE) & Stages `S3a`–`S3b` (`GPU4PySCF` $\omega\text{B97X-V/def2-TZVPP}$ `VPT2` + Analytical Cyvin–Watson Quartic Centrifugal Distortion)*:
  - Replacing CPU `B3LYP-D4/jun-cc-pV(T+d)Z`, analytical harmonic force constants $\mathbf{F}_0$ and semi-diagonal cubic force constants $\Phi_{rrs}$ ($36$ normal-mode displacements $\pm\delta q_r$, $\delta q_r = 0.030\text{ amu}^{1/2}\text{\AA}$) were computed on the RTX 3090 GPU at **`GPU4PySCF` $\omega\text{B97X-V/def2-TZVPP}$** (and diffuse-augmented **$\omega\text{B97M-V/def2-TZVPPD}$**).
  - Exact analytical quartic centrifugal distortion tensors $\tau_{\alpha\beta\gamma\delta}$ were derived from the analytical GPU Hessian inverse $(\mathbf{F}_0^{-1})_{ij}$ via the Cyvin–Watson relation [@Cyvin1968; @Watson1977], and Barone–Mills `VPT2` vibration–rotation interaction constants $\alpha_r^\alpha$ [@Barone2005; @Mills1972] were combined with `revDSD`/`DLPNO-SE` equilibrium constants:
    $$B_0^\alpha = B_e^\alpha(\text{revDSD/DLPNO-SE}) - \frac{1}{2}\sum_{r=1}^{3N-6}\alpha_r^\alpha(\omega\text{B97X-V/def2-TZVPP}), \quad \alpha \in \{A, B, C\}$$
    screening soft intermolecular modes below $120\text{ cm}^{-1}$ in the cubic anharmonic sum while retaining all $3N-6$ modes in the harmonic Coriolis and inertial-derivative terms ($\Delta B_{\mathrm{vib}}^B = -19.24\text{ MHz}$ vs. $-18.39\text{ MHz}$ from CPU `B3LYP-D4` on $\mathrm{HCOOH\cdots H_2S}$ `isomer-00`). Inertial defects $\Delta_0$ and Kraitchman coordinates $|a_s|, |b_s|, |c_s|$ [@Kraitchman1953] were computed across all 115 detectable isotopologues ($55$ in $\mathrm{H_2S}$, $60$ in $\mathrm{N_2O}$), alongside 1-D Meyer–Hougen Fourier-grid `DVR` tunneling splittings [@Colbert1992; @Meyer1968] for $\mathrm{HCOOH\cdots H_2S}$ `isomer-00`.

### 2.7. Coupled-Cluster Complete-Basis-Set Energetics & Counterpoise Protocol (`dlpno/make_dlpno_jobs.py`, `parse_dlpno.py`)

* *Scripts*: `publication/energetics/dlpno/make_dlpno_jobs.py` and `publication/energetics/dlpno/parse_dlpno.py`.
* *Methodology*: On each frozen `revDSD-PBEP86-D4/jun-cc-pV(T+d)Z` equilibrium geometry, domain-based local pair natural orbital coupled-cluster single-point energies with iterative perturbative triples (**`DLPNO-CCSD(T1)`**) [@Riplinger2013; @Riplinger2016; @Saitow2017] were configured with **`TightPNO`** thresholds ($T_{\mathrm{CutPairs}} = 10^{-5}$, $T_{\mathrm{CutPNO}} = 10^{-7}$, $T_{\mathrm{CutMKN}} = 10^{-3}$) [@Liakos2015] using Dunning's augmented correlation-consistent basis sets **`aug-cc-pV(T+d)Z`** ($X=3$) and **`aug-cc-pV(Q+d)Z`** ($X=4$) [@Dunning1989; @Kendall1992; @Dunning2001] (`aug-cc-pVTZ/C` and `aug-cc-pVQZ/C` auxiliary basis sets [@Hattig2005]).
* *Two-Point Complete-Basis-Set (`CBS(3/4)`) Extrapolation*:
  Hartree–Fock and correlation energies were extrapolated separately to the CBS limit [@Helgaker1997; @NeeseValeev2011]:
  $$E_{\mathrm{HF}}^{\mathrm{CBS}(3/4)} = \frac{E_{\mathrm{HF}}^{(4)} e^{\alpha\sqrt{4}} - E_{\mathrm{HF}}^{(3)} e^{\alpha\sqrt{3}}}{e^{\alpha\sqrt{4}} - e^{\alpha\sqrt{3}}} \quad (\alpha = 5.79), \qquad E_{\mathrm{corr}}^{\mathrm{CBS}(3/4)} = \frac{4^\beta E_{\mathrm{corr}}^{(4)} - 3^\beta E_{\mathrm{corr}}^{(3)}}{4^\beta - 3^\beta} \quad (\beta = 3.05)$$
* *Boys–Bernardi Counterpoise (`CP`) & Monomer Deformation (`4th-Leg`) Protocol*:
  For the anchor conformer of each motif family, four additional single-point legs per basis cardinal number $X \in \{3,4\}$ were evaluated on the dimer geometry: monomer $A$ in the full dimer basis ($E_A^{AB}(X)$, with monomer $B$ basis functions as ghost atoms `:`), monomer $B$ in the full dimer basis ($E_B^{AB}(X)$), monomer $A$ in its own basis at the deformed dimer geometry ($E_A^A(X)$), and monomer $B$ in its own basis at the deformed dimer geometry ($E_B^B(X)$) [@Boys1970]:
  $$\delta_{\mathrm{BSSE}}(X) = \left[E_A^A(X) - E_A^{AB}(X)\right] + \left[E_B^B(X) - E_B^{AB}(X)\right], \qquad \Delta E_{\mathrm{def}} = \left[E_A^A(\text{dimer geom}) - E_A^A(\text{relaxed mono})\right] + \left[E_B^B(\text{dimer geom}) - E_B^B(\text{relaxed mono})\right]$$
  yielding both raw ($D_e^{\mathrm{raw}}$), counterpoise-corrected ($D_e^{\mathrm{CP}} = D_e^{\mathrm{raw}} - \delta_{\mathrm{BSSE}}$), and half-CP ($D_e^{\mathrm{half-CP}} = D_e^{\mathrm{raw}} - \frac{1}{2}\delta_{\mathrm{BSSE}}$) dissociation energies alongside ZPE-corrected $D_0 = D_e - \Delta\mathrm{ZPE}_{\mathrm{revDSD}}$.

### 2.8. Relaxed 2-D Polar $(R,\theta)$ Potential Energy Surfaces & `NEB-TS` Pathways (`pes/make_pes_grid.py`, `run_pes.py`, `parse_pes.py`)

* *Scripts*: `publication/pes/make_pes_grid.py`, `run_pes.py`, `parse_pes.py`, `plot_pes.py`.
* *Polar Coordinate Definition*: The $\mathrm{HCOOH}$ monomer is placed in the $xy$-plane with the carbonyl carbon $\mathrm{C}$ at the origin $(0,0,0)$, the $\mathrm{C{=}O}$ vector aligned along $+\hat{\mathbf{x}}$ ($\theta = 0^\circ$), and the hydroxyl oxygen $\mathrm{O(H)}$ in the $+\hat{\mathbf{y}}$ half-plane ($\theta \approx +125^\circ$). The partner heavy atom ($\mathrm{S}$ of $\mathrm{H_2S}$ or central $\mathrm{N_c}$ of $\mathrm{N_2O}$) is placed on a polar grid $R \in [2.8, 4.8]\text{ \AA}$ ($\Delta R = 0.2\text{ \AA}$, 11 radial shells) and $\theta \in [0^\circ, 345^\circ]$ ($\Delta\theta = 15^\circ$, 24 angular sectors; 264 grid points total).
* *Two-Pass Constrained Relaxation & `NEB-TS`*:
  - **Pass 1 (`r2SCAN-3c`)**: At each sterically allowed $(R,\theta)$ grid point ($232$ points in $\mathrm{HCOOH\cdots H_2S}$, $237$ in $\mathrm{HCOOH\cdots N_2O}$), the radial distance $R$ and polar angle $\theta$ are held fixed while all internal monomer degrees of freedom and partner Euler orientation angles relax at `r2SCAN-3c`.
  - **Pass 2 (`wB97X-V/def2-TZVPP`)**: Low-energy valleys and inter-basin saddle ridges are refined at $\omega\text{B97X-V/def2-TZVPP}$.
  - **Minimum-Energy Pathways (`NEB-TS`)**: Climbing-image nudged elastic band transition-state (`NEB-TS`) [@Asgeirsson2021] calculations in ORCA 6.1.1 locate the exact first-order saddle points and activation barriers ($\Delta E^\ddagger$) connecting adjacent conformational basins.

### 2.9. Real-Space Wavefunction Topology (`QTAIM` + `IGMH`) & Local Energy Decomposition (`LED`) (`interaction/run_multiwfn.py`, `parse_led.py`)

* *Scripts*: `publication/interaction/run_multiwfn.py`, `parse_led.py`, `plot_interaction.py`.
* *Multiwfn `QTAIM` & `IGMH` Analysis*:
  - Molden wavefunction files (`orca_2aim`) generated from the `revDSD-PBEP86-D4/jun-cc-pV(T+d)Z` Kohn–Sham orbitals are analyzed in batch mode using **`Multiwfn 3.8`** [@Lu2012; @Lu2024].
  - **Quantum Theory of Atoms in Molecules (`QTAIM`)** [@Bader1990]: Intermolecular $(3,-1)$ bond critical points (BCPs) and $(3,+1)$ ring critical points (RCPs) are located by Newton–Raphson search on $\nabla\rho(\mathbf{r}) = \mathbf{0}$, extracting electron density $\rho(\mathbf{r}_{\mathrm{BCP}})$, Laplacian $\nabla^2\rho(\mathbf{r}_{\mathrm{BCP}})$, Lagrangian kinetic energy density $G(\mathbf{r})$, potential energy density $V(\mathbf{r})$, total energy density $H(\mathbf{r}) = G(\mathbf{r}) + V(\mathbf{r})$, and ellipticity $\varepsilon = \lambda_1/\lambda_2 - 1$.
  - **Independent Gradient Model based on Hirshfeld Partition (`IGMH`)** [@Lefebvre2017; @Lu2022]: Intermolecular reduced density gradient $\delta g^{\mathrm{inter}}(\mathbf{r}) = |\nabla\rho^{\mathrm{IGM,inter}}(\mathbf{r})| - |\nabla\rho(\mathbf{r})|$ isosurfaces colored by $\mathrm{sign}(\lambda_2)\rho(\mathbf{r})$ are evaluated on a medium-quality spatial grid to distinguish attractive hydrogen-bonding ($\mathrm{sign}(\lambda_2)\rho < -0.015\text{ a.u.}$, blue), weak van der Waals dispersion ($\mathrm{sign}(\lambda_2)\rho \approx 0$, green), and steric ring-closure repulsion ($\mathrm{sign}(\lambda_2)\rho > 0$, red).
* *`DLPNO-CCSD(T1)` Local Energy Decomposition (`LED`)*:
  - Using `! DLPNO-CCSD(T1) aug-cc-pV(T+d)Z TightPNO LED` [@Schneider2016; @Altun2018], the coupled-cluster interaction energy is decomposed into monomer electronic preparation ($\Delta E_{\mathrm{el-prep}}^{\mathrm{ref}}$), inter-fragment electrostatic interaction ($E_{\mathrm{elstat}}^{\mathrm{ref}}$), quantum-mechanical exchange ($E_{\mathrm{exch}}^{\mathrm{ref}}$), London dispersion ($E_{\mathrm{disp}}^{\mathrm{C-CCSD}} + E_{\mathrm{disp}}^{\mathrm{C-(T1)}}$), and non-dispersive electron correlation ($\Delta E_{\mathrm{non-disp}}^{\mathrm{C-CCSD}} + \Delta E_{\mathrm{non-disp}}^{\mathrm{C-(T1)}}$).
